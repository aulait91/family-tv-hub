# 우리집 영상관 — TV 웹 바로가기 MVP

부모님이 Android TV 셋톱박스의 **기존 TV 브라우저**로 이용할 수 있는 정적 웹사이트입니다. TV에서 APK를 설치할 필요가 없고, 영상은 외부 사이트의 기존 플레이어에서 재생됩니다.

## 구성
- `index.html`: TV 홈페이지. 드라마·영화·예능·자주 보기 메뉴, 리모컨 방향키 및 확인 버튼 지원.
- `catalog.js`: 부모님 TV에 표시되는 제목, 카테고리, 첫 영상 URL 목록.
- `admin.html`: 관리자 PC에서 작품을 추가/수정/삭제/순서 변경한 후 새 `catalog.js`를 다운로드하는 간단한 편집기.

## 빠른 사용법
1. `index.html`을 PC 브라우저에서 열어 첫 화면을 확인합니다. (실제 영상 링크는 샘플에 없습니다.)
2. `admin.html`을 PC 브라우저에서 열고 샘플 작품을 수정하거나 실제 작품을 추가합니다. 첫 영상(보통 1화)의 **직접 열리는 페이지 주소**를 등록하세요.
3. **목록 파일 내려받기**를 눌러 `catalog.js`를 다운로드합니다. 기존의 `catalog.js`를 새 파일로 교체하세요.
4. GitHub에서 **새 Public 저장소**를 만듭니다. 위의 `index.html`과 `catalog.js`를 업로드합니다. (`admin.html`은 개인용이므로 업로드하지 않아도 됩니다.)
5. 저장소의 Settings → Pages → Build and deployment에서 `Deploy from a branch`, `main` 브랜치, `/(root)` 폴더를 선택하고 저장합니다.
6. 배포된 `https://사용자이름.github.io/저장소이름/` 주소를 부모님 TV 브라우저의 시작 페이지(지원하는 경우) 또는 즐겨찾기로 등록합니다.
7. 네가 목록을 바꾸고 싶으면 PC `admin.html` → 새 `catalog.js` 다운로드 → GitHub 저장소에서 파일 교체 및 Commit → TV 브라우저 홈페이지 새로고침 순서로 업데이트합니다.

## TV 조작 및 검증
- 홈: 방향키와 확인 버튼으로 4개 카테고리 선택.
- 작품 목록: 제목 버튼으로 해당 영상의 첫 페이지로 이동 (동일 브라우저 탭).
- 뒤로: 브라우저 뒤로 가기 또는 목록 상단의 `← 처음으로`.
- 가상 마우스: 기존 TV 브라우저가 제공하는 기능을 그대로 사용합니다.
- 우선 PC에서 키보드 방향키/Enter 및 마우스 클릭을 확인하세요. 실제 LG 셋톱박스의 리모컨 이벤트 처리는 브라우저마다 다를 수 있어 실기 테스트가 필요합니다.
- 외부 사이트의 다음 회차 이동, 로그인, 팝업, 광고, 전체화면은 **원 사이트와 브라우저가 처리**합니다.

## 참고 및 주의
- GitHub Pages는 정적 HTML/JS를 무료로 배포할 수 있습니다. **무료 GitHub 계정은 Pages 저장소가 Public**이어야 합니다. 여기 올라간 작품 이름과 URL도 공개되니 비밀 정보나 로그인 토큰을 등록하지 마세요.
- `admin.html`은 별도 인증이나 서버가 없는 **로컬 편집기**이며, 직접 TV 데이터를 갱신하지 않습니다. 사이트 편집 후 GitHub에 `catalog.js`를 올려야 합니다.
- 부모님이 URL을 입력하지 않도록 홈페이지로 지정할 수 있는 TV 브라우저가 필요합니다.
- 새 브라우저 창이나 탭을 강제로 열지 않습니다. 브라우저의 뒤로 가기 동작은 외부 사이트가 자체적으로 히스토리를 조작할 경우 달라질 수 있습니다.
- HTTPS 사이트에서 HTTP 링크로 이동 시 브라우저마다 보안 경고가 나올 수 있으니 가능하면 HTTPS 주소를 등록하세요.
- 코드가 저장하는 개인 정보는 없지만, 호스팅 업체는 자체 접속 로그를 보유할 수 있습니다.
