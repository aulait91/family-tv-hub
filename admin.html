우리집 영상관 관리

여기는 관리자 PC용 페이지야. 등록한 제목과 URL을 수정한 뒤 목록 파일 내려받기를 눌러 catalog.js를 교체해 줘.

이 버전은 서버 없이 동작하는 무료 정적 사이트야. 수정 사항을 TV에 반영하려면 내려받은 catalog.js를 GitHub 저장소에도 업로드해 커밋해야 해. 이 관리자 화면 자체가 TV 목록을 실시간으로 수정하는 건 아니야.

작품 등록

등록할 때는 검색 결과 페이지가 아니라 부모님이 실제로 시청할 첫 영상 페이지의 주소를 사용하세요.

사용 순서: 제목 등록 → 목록 파일 내려받기 → 기존 catalog.js 덮어쓰기 → GitHub Pages 재게시 → TV 브라우저에서 홈페이지 새로고침.
